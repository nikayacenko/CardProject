CardProject — это полнофункциональная образовательная платформа для интервального повторения, которая использует машинное обучение для персонализации интервалов между повторениями карточек. В отличие от классического алгоритма SM-2, ML-модель учитывает 15+ контекстных факторов: время суток, уровень усталости, тип вопроса, историю ответов и другие параметры.

Ключевые возможности

ML-персонализация — нейросетевая модель на TensorFlow Lite предсказывает оптимальный интервал для каждой карточки

Android-приложение — нативное приложение на Kotlin с поддержкой офлайн-режима

Серверная синхронизация — FastAPI-сервер для хранения данных и дообучения модели

Аналитика обучения — детальная статистика по колодам, сессиям и прогрессу

Авторизация пользователей — регистрация и вход с JWT-токенами

Настраиваемый интерфейс — выбор цветовой темы, настройка режимов обучения
